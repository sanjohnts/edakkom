# Edakkom.com

The community digital archive of Edakkom, Kannur, Kerala — Malayalam at `/`, English at `/en`.

Built with React Router (static pre-rendering), TypeScript and Tailwind CSS.

```sh
npm install
npm start          # local development at http://localhost:5173
npm run build      # static site in build/client
npm run typecheck
npm run art        # regenerate the hero illustration
```

All page text lives in `app/content.ts`.
